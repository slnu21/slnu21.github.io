공부하고 정리한 내용을 기록하려고 블로그를 만들었습니다.
이 블로그는 **Jekyll + GitHub Pages** 로 정적 호스팅되며,
댓글은 **GitHub Issues**(Utterances)로 동작합니다.

## 왜 이 구성인가

- **서버/DB 불필요** — 푸시하면 GitHub 가 자동으로 빌드·배포합니다.
- **글은 Markdown** — `_posts` 폴더에 `.md` 파일만 추가하면 됩니다.
- **댓글은 Issues** — 별도 서비스 없이 내 레포 Issue 에 댓글이 쌓입니다.

## 글 쓰는 법

`_posts/YYYY-MM-DD-제목.md` 형식으로 파일을 만들고 아래 front matter 를 채웁니다.

```yaml
---
title: "글 제목"
date: 2026-05-30 10:00:00 +0900
categories: [개발]
tags: [Jekyll]
---
```

코드 블록, 표, 인용 등 일반적인 Markdown 문법을 모두 지원합니다.

> 댓글은 이 글 하단에서 GitHub 계정으로 남길 수 있습니다.
